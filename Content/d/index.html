Week 4

This week, we will finish with Ethernet for now. So far, we have seen how to provide physical ports, where we need network switches, how many ports, what speed. This week, we are going to look at logical network design, breaking up a flat Ethernet into Virtual LANs (VLANS) based on requirements to access applications, at specific security levels.

If I were building a network right now, I would also configure Network Access Control (NAC) into the design. Do a little background reading on the topic, I'm not going to cover it for now.

Study

  1. First understand VLANs.
  2. There are certain services we need on every LAN, I will discuss these here.

Practical Work

This week, carry out these exercises.

  1. Go through my practical work on VLANs.
  2. I show some simple technques for link aggregation. In practice, almost every host server uses something similar for redundant connectivity in data centre environments.
  3. Finally, I demonstrate Network Discovery, essentail for build, setup and test.

Later Study

If you run short on time now...these are items you need to know, but you do not need for the assignments.

  1. During setup and fault-finding, it is really useful to know some techniques for network discovery. We will examine this here.
  2. In a data center, there are few use-cases for WiFi, but we will cover some of the basics here.
  3. We have some use-cases for link aggregation, we will look at the basics here.
